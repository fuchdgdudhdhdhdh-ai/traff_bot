# Telegram Referral Bot v4 — Production

## Что реализовано
- `/start` и реферальные ссылки.
- Emoji-капча на русском.
- Обязательная проверка подписки на публичный канал.
- Ссылки на публичный и приватный каналы.
- Проверка подписки при доступе к разделам.
- Рефералы 1 уровня.
- Награда 50 ₽ помещается в холд на 30 часов и ежедневно проверяется.
- При отписке награда отменяется; после холда начисляется на доступный баланс.
- Администратор может вручную снять холд с конкретной награды — средства зачисляются мгновенно.
- Администратор может удалить реферала у пользователя: связь разрывается, реферал пропадает из списка, а с баланса пригласившего списывается 50 ₽ (или сумма фактической награды).
- PostgreSQL — постоянное хранилище.
- История финансовых операций.
- Заявки на вывод, возврат средств при отклонении.
- Автоматическое окно выплат по средам и воскресеньям UTC + ручной override; при закрытом окне пользователь видит сообщение «выплаты от 500 ₽, по средам и воскресеньям».
- Поддержка и полноценная переписка по тикетам.
- Закрытие тикетов.
- Роли администраторов.
- Поиск пользователей, карточка, блокировка, ручной баланс.
- Постраничный список всех пользователей бота с указанием пригласившего (@username или ID) и баланса.
- Редактирование текстов и загрузка фото через Telegram.
- `/health` для Render.
- Alembic migrations.

## Render
Создайте PostgreSQL на Render и Web Service.

Переменные:
- BOT_TOKEN
- DATABASE_URL
- SUPERADMIN_IDS
- PUBLIC_CHANNEL
- PUBLIC_URL
- PRIVATE_URL

Старт:
`alembic upgrade head && python main.py`

## Важно
Данные сохраняются при рестарте и новом деплое, поскольку находятся в PostgreSQL.
Не используйте SQLite для production на ephemeral filesystem Render.

## Канал
Бот должен быть администратором публичного канала, чтобы `getChatMember` мог проверять подписку.

## Пинг
Проверяйте:
`https://YOUR-SERVICE.onrender.com/health`
по расписанию, если это требуется вашим тарифом/архитектурой.

## Миграции
Текущая initial migration создаёт таблицы. Для будущих изменений добавляйте новые revision-файлы, а не меняйте уже применённую migration.


## Настройка через админ-панель
После первого запуска вам не нужно менять ссылки каналов в коде. В `config.py` остаются только `BOT_TOKEN` и `ADMIN_IDS` (подключение к PostgreSQL передаётся Render через `DATABASE_URL`).

Через Telegram-админку можно задавать публичный канал, публичную/приватную ссылки, тексты и последовательность важных сообщений. Важные сообщения имеют порядок; пользователь видит кнопку «Дальше», а при первом переходе показывается всплывающее предупреждение Telegram: «Внимательно ознакомьтесь: это очень важно!».

Администратор может открыть карточку пользователя и увидеть всех его рефералов первого уровня с `@username` либо Telegram ID, если username отсутствует, а также статус награды за каждого (в холде / начислено / отменено). Из этого же экрана можно снять холд с конкретной награды или полностью удалить реферала (со списанием 50 ₽ у пригласившего).

В админ-панели есть отдельный раздел «Все пользователи» — постраничный список всех зарегистрированных пользователей бота с их балансом и тем, кто их пригласил.
